- **Build 75: make games less samey (owner chose these, 16 Kasım; "absolutely the nicest ones"):** after the full balance (74), all solo + co-op, every mode where it makes sense (not PvP):
  - **Perk picks:** every few waves (e.g. 5) each player chooses 1 of 3 random perks that stack for the rest of the game (bullets bounce, kills heal, faster ability, more gold, bigger blasts…); class-aware pool, rarer strong perks later; shown on the HUD and end screen; host-authoritative (guests only send the pick).

  Not chosen: leave-or-stay extraction, class combos, weekly special rules. Ask the owner which wave starts feeling boring before tuning when these kick in.
